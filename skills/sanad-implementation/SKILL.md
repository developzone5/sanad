# Sanad implementation stage

Continue the implementation branch of [Sanad](../sanad/SKILL.md) from the current completed stage. Read [the implementation loop](../sanad/reference/loop.md) (Sanad Steps 1–5) in full before continuing. Follow the saved route (self-routed or boss-selected) and its applicable steps, linked references, review requirements, gate and publishing approval. A `review` route skips the expert panel; a `braintrust` route resumes the saved routing boss after the specialists. Do not infer a panel from this effort-setting skill. Reuse the existing task state and valid evidence; do not restart routing or completed stages.

This skill only activates the implementation effort within Sanad. It does not create a second workflow, spawn an agent, broaden the task or authorize publishing. Resolve Sanad's relative references against its own directory.

The invoking request must require implementation. A request to learn how to implement something stays in Sanad's teaching branch. If only a question remains, answer it without starting implementation. On the next user turn, enter through Sanad again so it can select effort for that request.
